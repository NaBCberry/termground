# TermGround 插件说明

> 当前版本：0.2.0  
> 适用平台：插件清单允许 Zotero 7 至 10；当前仅在用户现有 Zotero 环境中验证  
> 主要用途：从个人文献中积累中英术语，并在 PDF2zh 和 Translate for Zotero 的 CNKI 翻译中统一译名

## 1. 插件简介

TermGround 是一款面向 Zotero 的个人术语库插件。它从用户选中的 PDF 文献中识别中英文术语对应关系，保存术语、出处和证据，并把经过筛选的术语提供给翻译工具。

它要解决的主要问题不是“把一句话翻译出来”，而是让同一专业概念在多篇文献、不同翻译任务和长期研究过程中保持一致。例如，当术语库规定 `Automated Machine Learning` 译为“自动化机器学习”时，TermGround 会尽量让受支持的翻译工具沿用这一译名。

TermGround 0.2.0 支持两条翻译协作路径：

1. 为 PDF2zh 自动生成标准 CSV 术语表。
2. 在 Translate for Zotero 使用 CNKI 服务时，对命中的英文术语进行保护，并在翻译完成后恢复为术语库指定的中文译名。

## 2. 核心特点

### 2.1 本地个人术语库

术语库保存在 Zotero 数据目录中，不依赖独立数据库或云端账户。每条术语可以保存：

- 英文名称；
- 中文名称；
- 英文缩写；
- 推荐或候选状态；
- 提取来源和置信度；
- 原文证据、页码、章节和文献条目；
- 首次记录时间。

默认文件位置：

```text
Zotero数据目录/termground/terms.json
```

在当前 Windows 环境中通常为：

```text
C:\Users\用户名\Zotero\termground\terms.json
```

### 2.2 从 Zotero PDF 中提取术语

TermGround 直接使用 Zotero 已提取的 PDF 文本层，不单独解析 PDF。它会识别以下高价值信息：

- 中文术语后附英文名称，例如“自动化机器学习（Automated Machine Learning，AutoML）”；
- 英文术语后附中文解释；
- 英文全称与缩写关系；
- 中文期刊中的中英文关键词列表；
- 具有专业名词特征的中文候选词。

插件会过滤章节标题、期刊固定信息、基金编号、伪代码、破碎英文和明显不完整的词组，以减少错误术语进入术语库。

### 2.3 证据与来源追踪

TermGround 不只记录术语对，还记录它来自哪篇文献、哪一页、哪个章节以及对应原文。这样可以在术语有争议时返回原文核对，而不是只看到一条没有出处的机器推测。

### 2.4 候选词人工确认

置信度较高、具有明确双语证据的术语可以直接入库；边界不确定、缺少英文或需要人工判断的内容会进入“待确认候选”。

在候选审核中可以：

- 接受并入库；
- 修正中文术语边界；
- 补充英文名称；
- 拒绝错误候选；
- 暂时跳过。

人工修正的结果在同一英文术语出现多个译名时具有更高优先级。

### 2.5 PDF2zh 术语表同步

每次保存术语库时，TermGround 会同时生成：

```text
Zotero数据目录/termground/pdf2zh-glossary.csv
```

文件格式为：

```csv
source,target,tgt_lng
"Automated Machine Learning","自动化机器学习","zh-CN"
```

TermGround 本身只负责生成这个文件。PDF2zh 需要另外配置为读取该路径；当前用户环境中的 PDF2zh 服务端已经完成自动查找补丁。使用支持外部术语表的翻译引擎时，PDF2zh 才能将其作为翻译约束。

### 2.6 Translate for Zotero + CNKI 协作（实验性）

CNKI 是传统机器翻译服务，没有术语表上传接口，也不支持大模型提示词。TermGround 0.2.0 因此采用“术语保护”方案，并按 Translate for Zotero 2.4.7 的内部服务结构实现：

```text
用户选中的英文
  → 查找当前文本中出现的已入库术语
  → 用临时标记保护术语并附带指定中文译名
  → 调用 Translate for Zotero 的 CNKI 翻译
  → 移除临时标记并恢复指定译名
  → 显示最终译文
```

这一方案具有以下特点：

- 只处理当前文本中实际出现的术语，不发送整个术语库；
- 英文匹配不区分大小写；
- 优先匹配更长的术语，避免缩写或短词覆盖长词组；
- 不修改 PDF 原文；
- 没有术语命中时，CNKI 按原有方式工作；
- 命中术语时，以术语库保存的中文译名为准；
- Translate for Zotero 的缓存结果仍可正常使用。

## 3. 适用场景

TermGround 比较适合：

- 阅读同一研究领域的大量中英文论文；
- 统一论文、学位论文或综述中的专业术语；
- 为机器学习、医学、工程等缩写较多的领域积累个人语料；
- 在 PDF2zh 批量翻译中使用统一译名；
- 在 Zotero 阅读器中使用 CNKI 进行段落翻译，同时保留个人术语习惯；
- 建立带来源证据、可逐步人工校正的长期术语资产。

TermGround 当前不适合：

- 把没有文本层的扫描版 PDF 直接当作可提取文献；
- 从纯英文论文中自动推断高质量中英译名；
- 完全不经人工检查就建立高可靠术语库；
- 替代完整的翻译引擎或人工学术翻译；
- 让 CNKI 理解复杂的写作风格、上下文指令或领域提示词。

## 4. 安装与升级

安装文件：

```text
TermGround-0.2.0.xpi
```

安装步骤：

1. 打开 Zotero。
2. 进入“工具 → 插件”。
3. 点击插件管理页面右上角的齿轮按钮。
4. 选择“从文件安装插件”。
5. 选择 `TermGround-0.2.0.xpi`。
6. 确认安装或更新。
7. 完全退出并重新启动 Zotero。
8. 在插件管理页面确认版本为 `0.2.0`。

从旧版本升级不会主动删除 `terms.json`。为稳妥起见，升级前仍建议备份整个 `termground` 文件夹。

## 5. 基本使用方法

### 5.1 提取术语

1. 在 Zotero 文献库中选中一个或多个文献条目，也可以直接选中 PDF 附件。
2. 右键打开菜单。
3. 点击“提取术语（TermGround）”。
4. 等待右下角进度提示完成。
5. 查看新增术语对和证据数量。

如果显示“新增 0 对”，常见原因包括：

- 文献为纯英文，没有明确的中英对照信息；
- PDF 是扫描图片，没有可读取的文本层；
- Zotero 尚未建立 PDF 全文索引；
- 文献中的术语表达方式没有满足当前提取规则；
- 相同术语已经存在于术语库中。

### 5.2 审核候选术语

1. 在任意 Zotero 文献条目上点击右键。
2. 选择“待确认候选（TermGround）”。
3. 根据原文证据选择“入库”“拒绝”或“跳过”。
4. 如果中文边界有误，按提示修改中文术语。
5. 如果缺少英文名称，输入正确英文后再入库。

不要为了增加术语数量而接受不确定候选。错误术语一旦被翻译适配层命中，会直接影响输出译文。

### 5.3 查看统计

右键选择“术语库统计”，可以查看：

- 术语对数量；
- 证据数量；
- 已处理文献数量；
- 待确认候选数量；
- 术语库与 PDF2zh 术语表的保存位置。

## 6. 配置 Translate for Zotero 的 CNKI 翻译

### 6.1 Translate for Zotero 设置

1. 打开“Zotero → 编辑 → 设置”。
2. 进入 Translate for Zotero 设置页。
3. 将文本翻译服务设置为 `CNKI`。
4. 将目标语言设置为简体中文或 `zh-CN`。
5. 开启“超过 800 字符自动拆分翻译”。
6. 保留默认的 CNKI 广告移除正则表达式。

CNKI 不需要 API Key、模型名称、提示词或 Temperature 设置。

### 6.2 TermGround 设置

1. 打开“Zotero → 编辑 → 设置 → TermGround”。
2. 勾选“开启”。
3. 勾选“在 Translate for Zotero 的 CNKI 翻译中保护并统一术语”。
4. 重新启动 Zotero，使两个插件按正确顺序加载。

### 6.3 验证术语协助是否生效

假设术语库中已经存在：

```text
support vector machine → 支持向量机
```

在 Zotero PDF 阅读器中选中包含 `support vector machine` 的英文句子。Translate for Zotero 使用 CNKI 翻译后，最终结果中应采用“支持向量机”。

如果文本中没有任何术语库条目，翻译结果与普通 CNKI 翻译一致。

## 7. 配置 PDF2zh

TermGround 自身只负责生成和维护 CSV 术语表。PDF2zh 是否能使用术语表，还取决于所选翻译引擎是否支持 glossary 参数。

当前环境可以使用支持术语表的引擎，例如 SiliconFlowFree 或相应的大模型接口。若选择 Bing、Google、DeepL 等不读取外部 glossary 的传统服务，即使 CSV 文件存在，也不会自动采用其中术语。

检查步骤：

1. 确认 `pdf2zh-glossary.csv` 不只有表头，至少包含一条术语。
2. 在 PDF2zh 中选择支持 glossary 的翻译引擎。
3. 重新启动 Zotero 或 PDF2zh 服务。
4. 用包含已知术语的短文档测试译名是否一致。

## 8. 术语选择与冲突规则

同一英文术语可能在不同文献中对应不同中文译名。TermGround 当前按以下优先级选择最终译名：

1. 人工审核或人工修正的译名；
2. 具有明确双语证据、状态为 verified 的译名；
3. 状态为 attested 的译名；
4. 同优先级下选择置信度更高的译名。

在 CNKI 翻译中，文本出现重叠术语时优先匹配较长术语。例如同时存在 `machine learning` 和 `automated machine learning` 时，后者不会被拆成较短术语处理。

需要特别注意：术语通常与研究领域有关。同一缩写在不同领域可能具有完全不同的含义。当前版本尚未按文献集合或学科领域隔离术语，因此跨领域使用时应谨慎处理缩写冲突。

## 9. 数据、备份与隐私

### 9.1 本地保存内容

TermGround 的术语、证据和候选记录保存在本地 `terms.json` 中。PDF2zh 术语表也在本地生成。

建议定期备份：

```text
Zotero数据目录/termground/
```

### 9.2 网络传输边界

TermGround 的提取和术语库保存本身在本地完成。但是：

- 使用 CNKI 翻译时，当前待翻译文本以及被嵌入其中的命中术语会发送到 CNKI 服务；
- 使用 PDF2zh 的在线翻译引擎时，内容会按对应服务商的规则发送；
- TermGround 不会为了 CNKI 翻译而上传整个 `terms.json`。

处理未公开论文、敏感材料或受保密约束的文档前，应确认所用翻译服务的隐私政策和单位规定。

## 10. 已知限制

1. 当前提取规则主要针对含中英对照的中文学术文献，纯英文论文可能提取不到中英术语对。
2. PDF 必须具有可读取的文本层；扫描版文献需要先进行 OCR。
3. 自动提取仍可能产生边界错误、错误缩写或上下文相关的多义词。
4. CNKI 没有正式术语表接口，0.2.0 使用的是翻译前保护、翻译后恢复方案。
5. 极少数情况下，CNKI 可能改写临时保护标记，导致某个术语没有成功恢复。
6. CNKI 单次文本长度约为 800 字符；长文本依赖 Translate for Zotero 自动拆分。
7. 请求过于频繁可能触发 CNKI 验证或临时访问限制。
8. 当前版本没有可视化的完整术语表编辑器；已有错误条目需要通过审核流程或谨慎编辑 `terms.json` 处理。
9. 当前术语库是全局术语库，尚未按项目、分类、文献集合或学科建立独立子库。

## 11. 常见问题排查

### TermGround 菜单没有出现

- 确认插件已启用；
- 确认版本为 0.2.0；
- 完全退出 Zotero 后重新启动；
- 检查 Zotero 版本是否满足要求。

### 提取结果一直是 0

- 检查 PDF 是否能选中文字；
- 在 Zotero 中重建该 PDF 的全文索引；
- 优先测试含有中英摘要、双语关键词或括号术语定义的中文论文；
- 确认选中的是文献条目或 PDF 附件。

### CNKI 可以翻译，但术语没有统一

- 确认 Translate for Zotero 当前文本服务确实为 CNKI；
- 确认 TermGround 设置中的 CNKI 术语协助已勾选；
- 确认术语已经入库，而不只是仍在待确认列表；
- 检查英文原文是否实际包含术语库中的英文名称；
- 重新启动 Zotero，以确保 TermGround 成功挂接 CNKI 服务；
- 用较短的单句和明确术语进行测试。

### CNKI 提示访问被限制或需要验证码

在浏览器中打开 CNKI 翻译页面，完成一次人工验证，然后降低连续请求频率再重试。不要通过关闭 Windows 安全防护来解决 CNKI 网络限制。

### PDF2zh 没有使用术语表

- 检查 CSV 文件是否存在且包含数据行；
- 确认 PDF2zh 使用支持外部 glossary 的翻译引擎；
- 检查 PDF2zh 服务端是否仍保留 TermGround 术语表自动检测配置；
- 重新启动 PDF2zh 服务和 Zotero。

## 14. 后续改进方向

后续版本可以重点增加：

- 完整的术语表浏览、搜索、修改、删除和冲突处理界面；
- 按 Zotero 分类、项目或学科划分多个术语库；
- 导入和导出 CSV、TBX 等术语格式；
- 为纯英文论文增加人工译名补录或可选辅助提取流程；
- 显示每次翻译命中了哪些术语；
- 增加术语启用、停用和适用范围设置；
- 为 Translate for Zotero 的其他传统服务提供适配；
- 在用户选择大模型翻译服务时，动态注入少量命中术语，而不是发送完整术语库。

---

TermGround 的核心价值可以概括为：把分散在个人文献中的术语证据沉淀为可审核、可复用的本地术语库，再把这个术语库接入实际翻译流程，使长期文献阅读和学术写作中的专业译名更加稳定。
